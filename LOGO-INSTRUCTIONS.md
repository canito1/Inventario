# Instrucciones para el Logo PNG

## Para completar la configuración del logo:

1. **Guarda la imagen del logo de Security** como `public/logo.png`
2. **Dimensiones recomendadas**:

   - Ancho: 280-320 píxeles
   - Alto: 80-96 píxeles
   - Proporción: aproximadamente 3.5:1 (ancho:alto)

3. **Formato**: PNG con fondo transparente (recomendado)
4. **Calidad**: Alta resolución para que se vea bien en diferentes tamaños

## Ubicación del archivo:

```
public/logo.png
```

## Tamaños configurados:

- **Pequeño (sm)**: 80x24px - Para iconos pequeños
- **Mediano (md)**: 120x36px - Para sidebar y navegación móvil
- **Grande (lg)**: 160x48px - Para página de login

## El logo aparecerá en:

- Página de login (tamaño grande)
- Sidebar principal (tamaño mediano)
- Navegación móvil (tamaño mediano)

Una vez que agregues el archivo `logo.png` en la carpeta `public/`, el logo aparecerá automáticamente en toda la aplicación.

## Nota:

El componente ya está configurado para usar PNG y las dimensiones están optimizadas para mostrar el logo de Security correctamente.
